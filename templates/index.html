⚠️ 확인이 필요한 사항:

    💬 종목 심층분석 채팅 (Dify 챗봇①)

    내부 도구(네이버 금융 JSON + Serper 뉴스)로 수집한 실제 근거를 챗봇에 전달해 분석합니다.

    예시 종목:

    🤖 Dify 심층분석 챗봇

    종목코드를 입력하고 질문을 보내보세요. 위의 '도구 근거 사용'을 끄면 도구 없는 AI와 차이를 비교할 수 있습니다!

    🔍 백엔드가 수집한 실제 근거 (JSON 요약)

    AI에게 전달된 네이버 시세·실적·뉴스 원본입니다.

    질문을 전송하면 수집된 근거 데이터가 여기에 표시됩니다.

    ⚖️ 리밸런싱 도우미 (순수 Python 몬테카를로)

    AI 감이 아닌 최근 1년 주가 데이터(FinanceDataReader)와 3,000회 몬테카를로 시뮬레이션으로 최적 비중을 계산합니다.

    포트폴리오 예시:
    최근 1년 주가 수집 및 3,000회 몬테카를로 시뮬레이션 계산 중...

    🏆 최대 샤프지수(효율적 프론티어) 최적 포트폴리오

    🥧 권장 투자 비중

    📈 효율적 프론티어 (위험 vs 기대수익률)

    📋 개별 종목 최근 1년 통계

    종목코드 권장 비중 연율화 수익률 연율화 변동성 샤프지수 최대낙폭 (MDD)

    📊 기술지표 차트 + AI 해석 (Dify 챗봇③)

    FinanceDataReader로 MA·RSI·MACD·볼린저밴드를 직접 계산해 차트로 그리고, 계산된 숫자를 챗봇③에 주입해 설명합니다.

    예시 종목:
    주가 데이터 수집 및 기술지표 계산 중...

    📌 최신 기술지표 계산 결과 (Dify 챗봇③ 주입 데이터)

    📈 주가 + 이동평균선(5/20/60) + 볼린저밴드

    📉 RSI (14일) 추이 (과매수 70 / 과매도 30)

    🤖 기술지표 설명 전용 챗봇 (Dify 챗봇③)

    질문 시 위에 계산된 최신 숫자(latest_summary)가 보이지 않게 자동 주입됩니다.

    차트와 기술지표 계산이 완료되었습니다! 현재 RSI, 이동평균선, 볼린저밴드 상태가 궁금하시면 질문해 보세요.
